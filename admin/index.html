Selamat datang kembali.

Masuk untuk mengelola website perusahaan.

Panel admin membutuhkan PHP. Unggah isi folder dist ke hosting PHP, lalu buka domain-Anda/admin/. Untuk mencoba di komputer, jalankan start-website.cmd.

Buat akun admin Anda. Buka File Manager hosting, aktifkan tampilan file tersembunyi, lalu buka .hpo-private/setup-key.php. Salin nilai key ke kolom di bawah. File dibuat otomatis setelah halaman ini dibuka.
